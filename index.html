Standings

    Scoring rules used

    Crystals: Quartz $2, Rubellite $3, Emerald $4, Sapphire $5, Ruby $7, Amber $9. Sets of one color: 3 = +3, 4 = +6, 5 or more = +10. Each unstable crystal is −3. The player with the fewest crystals in their chest loses 5 (all tied players lose 5). Ties go to the most Quartz, then Rubellite, and so on up the value ladder.

    Count every crystal a player owns, cart and chest together. Enter the chest count separately for the Reckless Miner penalty.
